# 0.10.0：性能与可靠性

本版把启动、书架、图片缓存和数据保留作为重点，同时增加小说工具与视频离线下载。性能结果应以目标手机测量为准；本次验证覆盖功能行为，没有宣称真实网络加速倍数。

## 数据读取与更新

AppModel构造时不查询SQLite规则、收藏、历史及追更记录，先建立界面状态，再在后台读取。数据库提交后按“规则／订阅”和“收藏／历史／追更”两类发出变化通知，页面合并处理，书架不再每15秒重读数据库。滚动浏览搜索结果时暂存新结果，用户点击“新结果”后再更新作品列表，减少自动重排造成的误点。查询串行执行，避免连续更新不断取消大查询；界面层的写操作按顺序在后台完成，离开后排空已有写入再关闭数据库。源分类结果延迟缓存，来源按ID查找；收藏和历史增加更新时间索引。

换源确认会等待收藏、章节、原线路进度和阅读偏好写入成功后再打开内容，避免后台写入与页面读取抢先。失败有提示，原始章节索引仍用于进度保存。进度写入、追更与规则订阅不会因清理临时缓存被删除。

## 图片与缓存

封面、正文图片及漫画预取共享一个Coil加载器，统一图片内存和磁盘预算。图片内存缓存约10%应用堆，磁盘图片缓存192MiB；漫画请求按屏幕宽度和最长8192像素的解码尺寸约束，以FIT缩放防止SVG被按长边异常放大。特别长的图片可能下采样，本版未加入分块缩放阅读。低内存通知会释放已缓存位图。

“发现 → ＋ → 下载与缓存 → 缓存管理”分别清理图片、在线播放临时缓存和正文／目录内存缓存。播放临时缓存上限256MiB，须先停止播放器才能清理。活跃请求可能再次生成临时缓存。清理不会移除本地小说、字体、收藏、进度及视频下载。

## 小说工具

- 详情目录的放大镜或阅读目录的搜索框按章节名筛选；正序／倒序和过滤都保留原始章节号。
- 阅读时点击正文唤出操作，再点顶栏搜索图标，可搜索本章正文。本地导入小说可选择“全书 · 本地”。逐章读取、可取消、最多200处结果，点击跳到对应章节／段落；在线正文仅搜索当前已加载章节，不为全文搜索下载整本书。
- “设置 → 字体、边距、常亮 · 更多设置”中可启用音量键翻页：音量减下一页、音量加上一页。菜单、设置和正在听书时使用正常音量控制；离开阅读后解除拦截。
- 同一设置页可导入TTF／OTF字体，最大20MiB，校验字体后保存到私有目录；字体应用于滚动与分页正文，可恢复系统字体。
- 自动滚动会使用上下滚动模式，可调速度，在点击页面、切后台或本章结束时停止。翻页位置在退出时保存，滚动中的偏好写入适度合并。

## 视频离线下载

在播放器设置点“下载当前集”，然后到“发现 → ＋ → 下载与缓存”管理任务。默认仅Wi-Fi，可明确切换为允许移动网络；仅Wi-Fi开启时，在移动网络下不会开始解析和下载新任务。后台下载使用系统前台服务与持久任务索引，当前最多一个任务、两个下载工作线程；暂停、继续、失败重试和删除均保留明确状态。Android 13及以上可开启下载通知，通知进入下载列表。

常见MP4使用连续文件下载，点播HLS使用Media3下载器按选定轨道下载，避免把所有清晰度作为一份播放内容使用。已下载视频保存在App私有目录，与播放临时缓存分离，普通缓存清理不会删除。下载保留原始作品、集数、线路和页面地址；离线播放不提供网络回退，断网仍能读取已完成内容。M3U8保存为App内可播放的缓存与分片，不自动合并导出MP4。

暂停的连续文件进度以实际已保存的缓存字节为依据；进程重新建立后可继续任务。系统强制停止期间不会继续传输，重新打开后可恢复。开始前要求至少256MiB可用空间，下载过程中低于128MiB会停止并保留已有部分。下载准备有超时和取消入口；长时间后台任务受到系统限制时暂停，不承诺无限后台运行。

下载使用站点实际提供的媒体地址。链接过期、需要验证、直播或受保护媒体可能无法完整下载，需要重新解析或更换来源。规则能导入、能搜索不等同于站点支持下载，本版未重新认证全部263条真实站点。已有HLS广告过滤仍在播放阶段运行，下载缓存保留原始内容，不能保证自动识别所有广告。

## 验证依据

100项单元检查；43项Android 35模拟器检查，加2项明确结束进程后的下载检查。新增检查验证：

- 持有数据库写锁时，构造界面模型仍能返回，解锁后后台完成数据读取；收藏变化在无轮询情况下显示，回滚不暴露半成品。
- 超长位图尺寸受控，共享图片加载器；清理缓存保留书籍与字体。
- 本地全文结果跳章、目录筛选索引、音量键、字体以及自动滚动后台停止。
- MP4和点播HLS完成下载后断网播放；HLS保留轨道选择，原始集数保存；暂停后使用Range续传。
- 进程结束再打开后，已完成视频可在服务器关闭时播放，暂停任务可恢复并继续下载。

本地升级快照验证原收藏、规则、历史和规则订阅原字段保持；追更的检查时间允许后台正常刷新。原有播放、画中画、听书、动态解析、规则订阅和阅读检查继续回归。

实现参考：[Media3离线下载](https://developer.android.com/media/media3/exoplayer/downloading-media)、[Coil共享加载器](https://coil-kt.github.io/coil/image_loaders/)。具体API以项目锁定的Media3 1.9.0和Coil 2.7.0为准。

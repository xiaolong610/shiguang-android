# 0.11.0：Shiguang 英文界面

本版提供同一安装包内的英文／简体中文界面。英文名称为 Shiguang，保留原包名、签名与拾光精灵图标，可以覆盖安装。入口为“发现 → ＋ → 语言 / Language → English”，首次默认跟随系统；中文系统显示中文，其余系统使用英文后备。

## 实现范围

- 695项中英文Android资源，覆盖发现、书架、来源、规则导入与订阅、详情、阅读、听书、播放、下载、缓存和错误提示。动态数字和字段通过带编号的格式参数插入，不拼改站点协议。
- Android 13及以上使用LocaleManager，声明可用语言并与系统应用语言设置同步。Android 8—12保存本机语言偏好，在活动与服务入口包装语言配置。切换语言会重建页面，保留数据库和保存的阅读位置。
- 分类、翻页方式、朗读风格使用动态文案，避免枚举或静态缓存把界面锁定在上次语言。ViewModel在语言变化后刷新显示状态。
- 源的ID、规则JSON字段、种类枚举、网址、章节原索引及匹配用正则不随语言变化。网站返回的作品名、章节名、正文不自动翻译；已有收藏和历史保留原数据。内置小说和漫画为中文原创内容。
- 原版本持久保存的订阅状态文字在刷新前可能沿用旧语言；错误判断兼容中英文，不因切换语言漏判失败。日期按所选界面语言格式化。
- 离线系统听书按当前章节正文中的中英文字符选择离线音色。与界面语言无关，需要手机安装相应语音包。本版没有新增在线翻译服务，AI语音服务是否支持英文取决于配对服务本身。
- 移除规则订阅页每5秒的重复数据库读取，继续使用LibraryEvents更新。调整英文详情听书按钮高度，避免文字被裁切。

## 维护

英文资源位于`app/src/main/res/values/strings.xml`，中文资源位于`values-zh/strings.xml`。资源ID保持稳定；新增文案应同时补齐两种语言，格式参数必须对应。`tools/localization/validate.py`检查重复、空值、遗漏及格式参数；`--write-fallbacks`可同步JVM测试使用的中文后备表。运行期使用Android本地资源，不向外部翻译服务发送界面或阅读内容。

专项设备检查覆盖双语格式化、语言双向切换和原始收藏保留、英文来源分类／导入／订阅／缓存、英文小说全文定位以及播放／漫画设置。原有中文阅读、搜索、追更、换源、在线播放、下载和画中画继续回归。

本次主要验证平台为Android 35模拟器；Android 8—12兼容路径已实现并通过构建检查，未在旧版真机上验收。不声称全部网站已重新测试，也不把界面英文版等同于新增英文内容源。

参考：[Android应用语言](https://developer.android.com/guide/topics/resources/app-languages)。

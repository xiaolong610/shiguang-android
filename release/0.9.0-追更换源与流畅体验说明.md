# 拾光 0.9.0 · 追更、换源与流畅体验

按约定顺序完善四项功能，保留「拾光精灵」图标。

1. 收藏追更：书架显示新增章节／集数及未读数量，支持“有更新”筛选、手动刷新和自动检查。首次检查建立基线，网站失败保留上次目录。自动任务约每12小时检查，受系统省电和联网条件影响。
2. 同名作品聚合与换源：发现页将不同源中的同分类、同规范名称作品合并展示，保留季数、年份和版本差异。详情和播放器设置可搜索其他启用来源；确认目录位置后换源。视频支持同集时间位置沿用，小说／漫画从匹配或手选章节开头开始。收藏可切到新来源，原源进度保留。
3. 在线播放：画面中央双击暂停／播放，长按临时至少2倍速，松手、切后台恢复原倍速；原有进度条及播放按钮仍可使用。全屏返回先回到竖屏窗口，再返回才离开播放器；切换过程中保留播放服务、暂停状态及进度。
4. 阅读流畅度：小说及漫画目录正文使用有上限的会话缓存，非计费网络预取下一章／话，漫画提前准备后续三张图片。图片失败可单张重试，保留当前章节和阅读位置。当前预取不是离线下载管理。

换源匹配采取保守策略：小说／漫画优先唯一的章节全名匹配；视频允许集数数字格式不同，但上下集、预告等后缀须一致。无法可靠匹配时必须手选，避免只按章节序号跳错内容。同名聚合仅基于规则提供的名称与分类，用户换源前仍需核对版本。

安装 `shiguang-0.9.0.apk` 或本地“拾光-0.9.0-追更换源版.apk”，覆盖旧版，无需卸载。versionCode 10，沿用原包名及签名；数据库增量升级保留收藏、规则和进度。

# Shiguang 0.11.0

- 新增英文界面，保留简体中文；在“发现 → ＋ → 语言 / Language”选择English，也可跟随系统。
- 695项双语文案覆盖主要页面、阅读、听书、播放、下载、缓存、规则及错误提示。网站作品名、章节与正文保留原文，原收藏及进度继续使用。
- 系统离线听书按书籍正文选择中文或英文离线音色，需要安装对应语音包。AI服务的英文支持取决于配对服务。
- 规则订阅页取消5秒轮询，按数据变化更新；调整英文详情听书按钮，避免裁切。
- 沿用原包名和签名，可直接覆盖安装；原0.6.0规则包继续兼容。未新增或重新认证英文网站规则。

# 拾光 0.8.0 · 收藏与翻页

## 收藏状态

作品详情右上角统一为带文字的按钮。未收藏时为蓝色“＋ 加入收藏”，收藏后为绿色“✓ 已收藏”；再次点击已收藏可取消。小说、漫画、影视、动画共用同一套状态。

## 小说翻页

点正文中间展开操作栏，进入“设置 → 翻页方式”：

- 上下滚动：保留原来的连续滚动和文字选择。
- 左右滑动：左滑下一页，右滑上一页，也可点击两侧翻页。
- 点击翻页：左侧上一页、右侧下一页，直接切页；中间展开操作。

横向模式按屏幕宽高、字号、行距、字体和页边距分页。章末右侧翻页进入下一章；章首左侧翻页可回上一章末尾。偏好、阅读位置自动保存，书签、目录跳转与听书跟随继续可用。

## 漫画翻页

点页面中间展开操作栏，进入“设置”：

- 上下条漫：纵向连续阅读。
- 左右翻页：向左滑下一页；点击右侧下一页。
- 日漫右翻：向右滑下一页；点击左侧下一页。

横向模式每屏显示一张完整图片。各模式可以切换，记住图片位置。图片加载失败时可单独重试。最后一屏提供下一话入口。

## 章节和选集排序

各类作品详情的目录／选集标题右侧均提供“正序 ↑ / 倒序 ↓”。小说和漫画阅读中的目录也支持排序；按小说、漫画、视频分别记住偏好。排序只调整显示顺序，实际章节编号、收藏、续读和自动下一集仍按内容源的原始章节顺序处理。

## 安装

将“拾光-0.8.0-收藏与翻页版.apk”传到安卓手机并覆盖安装，无需卸载旧版。安装包包名、签名和数据库版本保持兼容。0.6.0 分类规则包继续使用。

页面截图中的“海边来信”“阅读交互验证”为临时验收内容，未预置到安装包。

# 拾光 0.10.0 性能与离线版

可直接覆盖旧版安装，保留规则、收藏、阅读／播放进度和本地小说。

1. 启动时后台读取规则、收藏与历史；书架取消15秒轮询，按数据提交后的变化更新。来源分类和查找复用结果，换源完成写入后再进入内容。
2. 图片加载与漫画预取共享缓存；图片磁盘缓存上限192MiB，播放临时缓存256MiB。发现右上角“＋ → 下载与缓存”可查看占用、分类清理，已下载视频与书籍会保留。
3. 小说详情及阅读目录支持章节名搜索；阅读顶栏搜索图标支持本章正文搜索，本地导入小说可逐章全文搜索并跳转，最多展示200处结果。
4. 小说更多阅读设置加入音量键翻页、TTF／OTF字体导入（最大20MiB）与自动滚动。自动滚动在点击、后台或本章结束时停止；听书与菜单中的音量键仍调整音量。
5. 播放器设置可下载当前集，支持常见MP4和点播M3U8，默认仅Wi-Fi；下载列表可暂停、继续、重试、删除和离线播放。视频存于App私有目录，普通缓存清理不会删除；M3U8不自动合并导出为MP4。

100项单元检查、43项安卓模拟器回归及2项跨进程下载验证通过。升级前后原有核心记录保持一致，安装包签名沿用旧版。真实网站与目标手机表现仍需实际验证，下载能力取决于来源提供的媒体；临时链接过期时可能需要重新解析或换源。

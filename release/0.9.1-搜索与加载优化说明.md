# 拾光 0.9.1：搜索与加载优化

本次处理启用大量规则后四类内容搜索、加载缓慢的问题，保留现有收藏、规则、进度和追更数据，可覆盖升级。

- 结果边到边显示，搜索中可以打开作品；支持停止，停止后保留已有结果。
- 普通搜索最多6个源并发，动态网页单独排队；快源优先，连续失败源暂时排后。
- 最新列表先查6个源、单字8个、其他关键词12个。点击“继续查找”每次最多增加24个，更多菜单可“搜索全部剩余来源”。不会改变规则启用状态。
- 本地已见作品支持单字、片段、分词、漏字和有限错字匹配，提供已知作品名建议。精确标题优先。首次未知作品仍依赖网站搜索，必要时最多增加两次较短关键词请求。
- 换关键词取消旧请求，搜索和详情分队列，网页解析移到后台；详情两分钟短缓存，追更和重试强制刷新。
- 取消无人使用的阅读请求，避免离开后继续占用加载位置；保留章节预取接续能力。

97项单元检查及32项Android 35模拟器检查通过，覆盖四类快慢源、少字搜索、搜索范围、数据库升级及原有播放、阅读、追更和订阅功能。升级后原有记录保持一致，签名沿用此前版本。

截图中的验证作品和源仅用于本地测试，未预置到安装包。真实网站速度、可用性和手机后台行为仍以实际设备为准。规则JSON版本不变，仍可直接导入。
